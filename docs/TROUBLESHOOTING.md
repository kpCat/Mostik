# Диагностика проблем

**Нет SDK/workload.** Выполнить Doctor и BUILD_WINDOWS. Visual Studio без Android-компонентов
недостаточна. Ошибка XA5300 означает, что SDK/JDK не найдены; указать реальные каталоги.

**C# ошибка ML Kit.** При первой сборке сверить реальные пространства имён/сигнатуры
в восстановленной версии 117.0.3.8. Исходная поставка их не проверяла компилятором.
Не исправлять путём удаления переводчика или возврата исходного текста вместо перевода.

**libvosk.so / DllNotFoundException.** Проверить ZIP APK и наличие `lib/arm64-v8a/libvosk.so`
и всех её native-зависимостей из AAR. Проверить ABI устройства. Не использовать Windows DLL
и не добавлять JNA, когда вызовы идут через C API. Source generator ошибки не относятся к Vosk.

**Resources/google_translate_badge отсутствует.** Выполнить Get-BuildAssets.ps1. Если официальный
пакет изменился, проверить его содержимое и выбрать правильный PNG через -BadgeEntry.
Не обходить атрибуцию пустой картинкой. Проверить, что бейдж читаем и не растянут.

**Hash/размер Vosk не совпал.** Оставить установку заблокированной. Проверить официальный
адрес, исключить HTML-страницу прокси/каптив-портала, повторно скачать и сравнить с указанной
версией и проверяемым источником SHA. Обновление каталога — отдельное объяснённое изменение.

**Перевод есть, звука нет.** Проверить громкость мультимедиа, выбранный TTS-движок,
офлайн-голоса RU и PL, Bluetooth-маршрут звука. Нажать тесты каждого голоса.
Проверить в авиарежиме. Если движок не предоставляет нужного голоса, это не решается
установкой модели распознавания: это разные компоненты.

**Слишком медленно.** Сначала измерить model load/ASR/ML Kit/TTS отдельно. Направление меняется —
меняется модель Vosk. Не обещать исправить latency переходом на большую нейросеть.
Не держать обе модели без проверки RAM и 20 чередующихся реплик на Redmi.

**Приложение переводит неправильно.** Проверить распознанный текст. Включить ручную проверку,
разбить длинную мысль на короткие фразы, уточнить число/отрицание. ML Kit переводит RU/PL
через английский; некоторые смысловые ошибки останутся даже при верном распознавании.

**После Home пропала запись.** Предусмотрено: фонового микрофона нет. Вернуться и начать заново.
Загрузку пакета Vosk не сворачивать; пауза/докачка не реализована.

**После отмены расходуется сеть.** Уже начатый ML Kit download может продолжиться в SDK.
Отмена ожидания не отменяет его физически. Для прекращения сетевого трафика отключить сеть.

**APK не обновляется из-за подписи.** Сохранить прежний отладочный/релизный ключ. Не запускать
uninstall автоматически: потеряются пакеты. Решение с удалением согласовать с пользователем.

**Сбой только на телефоне.** Скопировать встроенную диагностику и указать точные действия.
При необходимости записать ограниченный logcat локально; перед передачей удалить диалоги,
персональные данные и чувствительные пути. Полный binlog также не публиковать без проверки.
