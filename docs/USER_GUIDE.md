# Разговор через «Мостик»

## Подготовить заранее

Нужна сеть для первой установки моделей речи/перевода и голосов, а не для каждой реплики.
Откройте «Пакеты и голоса» → «Загрузить языковые пакеты». Для осторожного расходования
трафика по умолчанию включена загрузка по Wi-Fi. Не сворачивайте приложение во время
скачивания Vosk: отменённый ZIP будет скачиваться заново.

Кнопка «Установить офлайн-голоса» открывает системный движок. Меню зависит от версии
MIUI/Android и выбранного синтезатора. Нужно установить **русский** и **польский** языки
для автономного синтеза, а не только выбрать язык интерфейса. Вернитесь, нажмите
«Перепроверить компоненты», затем послушайте русский и польский тесты. Прибавьте
громкость **мультимедиа**. Если движок не предлагает польский офлайн-голос, голосовой
режим ещё не готов: приложение не подменяет его сетевым голосом.

Установленные голоса отмечаются по данным движка. Проверка на слух обязательна.
Авиарежим может оставить Wi-Fi включённым: выключите его отдельно. Перезапустите
«Мостик», выполните «Проверка перевода и голосов без сети», затем обе кнопки разговора.

## Общаться

Нажмите «Я говорю», дождитесь «Говорите», скажите короткую русскую фразу.
После паузы приложение должно завершить её, показать польский перевод и озвучить.
Теперь нажмите «Собеседник говорит», дождитесь готовности микрофона и дайте человеку
сказать по-польски. Ответ должен прозвучать по-русски.

При каждой смене языка подгружается другая модель: не говорите во время сообщения
о загрузке. Говорить нужно по очереди, не поверх озвучки приложения. Второе нажатие
той же кнопки завершает запись вручную. «Остановить / отменить» отменяет операцию.

## Исправить распознавание

Включите «Проверять текст перед переводом». Исправьте исходный текст после записи,
затем нажмите нужное направление в секции «Перевести исправленный текст с Google».
Ручной ввод работает без микрофона. «Повторить озвучку» повторяет уже показанный перевод,
а не исходную реплику. «Очистить разговор» удаляет текст с экрана.

Одна запись ограничена 30 секундами. Для разговора лучше одна-две короткие мысли.
Не считайте правильное распознавание доказательством правильного перевода: числа,
отрицания и незнакомые имена могут испортиться на любом этапе. Для важных решений
покажите исходный/переведённый текст собеседнику и уточните смысл.

## Сбой

Сначала прочтите сообщение на экране. При отсутствии голоса перевод остаётся виден.
«Скопировать диагностику для Codex» переносит техническую информацию в буфер обмена,
но не текст разговора. После этого её можно передать в новую задачу вместе с описанием
действий. Не прикладывайте чужой разговор или полные логи без проверки содержимого.
