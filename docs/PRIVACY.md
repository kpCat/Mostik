# Данные и автономная работа

«Мостик» предназначен для очного разговора RU ⇄ PL. Собственного аккаунта и сервера нет.

Аудио микрофона передаётся локальному Vosk как PCM в оперативной памяти. Приложение
не сохраняет аудиозаписи, не отправляет их на сервер и не ведёт историю разговоров.
Распознанный текст и перевод видны на экране. Кнопка очистки удаляет их с экрана;
при уничтожении Activity они не восстанавливаются из намеренно сохранённой истории.
Это не обещание форензической очистки RAM, защиты от скриншотов или системного предпросмотра.

Входной и выходной текст ML Kit, согласно условиям Google, обрабатывается на устройстве
и не отправляется Google. При этом ML Kit может отправлять технические метрики работы
API и получать информацию для совместимости/обновления моделей, когда сеть доступна.
Поэтому заявление «никаких сетевых соединений никогда» было бы неверным.
Документ Google: https://developers.google.com/ml-kit/terms

Интернет нужен для первой загрузки моделей и установки голосов. Вызов перевода в
режиме разговора не инициирует загрузку модели через код приложения. Уже начатая
загрузка ML Kit может продолжаться после отмены ожидания в приложении: публичная
обёртка не предоставляет используемой здесь операции физической отмены download.

Vosk загружает только адреса из встроенного каталога; размер и SHA-256 проверяются.
Режим Wi-Fi проверяет активную сеть перед загрузкой и во время чтения. Это не жёсткая
привязка сокета к сети: при мгновенной смене сети ОС небольшой объём мобильного трафика
нельзя исключить. Для абсолютного запрета мобильного трафика выключите мобильные данные.

Озвучка использует сторонний установленный системный TTS-движок. Выбираются только
голоса, объявленные локальными и установленными; сетевой fallback в коде отсутствует.
Поведение самого движка регулируется его условиями. Проверяйте оба голоса в авиарежиме.

Разрешения: микрофон для записи, доступ к сети для подготовки, состояние сети для проверок.
Нет доступа к контактам, SMS, геолокации или общему файловому хранилищу. Модели находятся
в private-каталогах приложения. Backup отключён; удаление приложения удалит его модели.
Чекбоксы настроек сохраняются локально. Фоновое прослушивание не реализовано.

Диагностика копируется в clipboard только отдельным нажатием пользователя. Она включает
версию ОС/модель устройства, готовность компонентов, идентификатор TTS, названия голосов,
времена операций и тип последней ошибки; не содержит текст разговора/PCM.
Содержимое clipboard далее обрабатывается Android и приложением, куда вы его вставите.
