# Пакеты и контроль целостности

## Распознавание речи Vosk

Каталог `data/models.json` содержит ровно два пакета. Скачивание — с официального
сервера Alpha Cephei по HTTPS, без редиректов. Все приведённые значения взяты из
опубликованных метаданных; сами ZIP в среде подготовки не скачивались.

| Язык | Пакет | Размер ZIP, байт | Лицензия по каталогу Vosk |
|---|---|---:|---|
| Русский | vosk-model-small-ru-0.22 | 46 236 750 | Apache-2.0 |
| Польский | vosk-model-small-pl-0.22 | 52 979 372 | Apache-2.0 |

Итого: 99 216 122 байта ≈ 94,62 МиБ, то есть примерно 95 МиБ/99 МБ в зависимости
от системы единиц. Это только сжатые пакеты распознавания; не APK и не все данные приложения.

SHA-256 RU:
```
961d5ff98a17f4aa6de69864d0aa71fa5bac682301d2b5d17a3f24c5c99a46d4
```
SHA-256 PL:
```
c4cd16498ea544f446f9e9a55cbd602b71cfe5a2b6f2b0834d81e1b6fce15f0d
```

Происхождение SHA и точных размеров: Git LFS-манифест зеркала `rhasspy/vosk-models`,
commit `e7ac2109d134b5f2404ba95389b2fb51916d4cab` (SOURCES.md).
Названия и лицензии сверены с официальным каталогом Vosk. Первая установка должна
подтвердить совпадение именно официально скачанных ZIP с этими значениями.
Если не совпадает — **остановиться и расследовать**, не убирать проверку.

Установка проверяет точный размер загрузки, SHA, безопасный корень ZIP, отсутствие
traversal/symlinks/дубликатов и лимит 256 МиБ распакованного содержимого на модель.
После проверки обязательных файлов ставится маркер `.complete` и модель переносится
из staging в окончательный каталог. Незавершённая загрузка не считается установленной.
Поддержки HTTP Range/докачки пока нет. Скачанные ZIP после установки удаляются.

Официальная общая оценка Vosk для малых моделей — около 300 МБ RAM на модель;
это не замер Redmi и не память всего процесса. Держим одну модель, замеры делать отдельно.

## Перевод ML Kit

Русская и польская модели управляются SDK, вручную не извлекаются из сторонних APK.
Официальное руководство указывает ориентир порядка 30 МБ для языковой модели;
фактический трафик/диск зависят от SDK и содержимого пакетов. Для неанглийской пары
используется английский промежуточный перевод внутри SDK.

## Озвучка Android

Размеры зависят от установленного синтезатора и выбранных голосов. Эти данные загружает
системный движок, а не ModelStore. Приложение проверяет `isNetworkConnectionRequired`
и признак `notInstalled`, но окончательный критерий — слышимая работа без сети.

Перед подготовкой разумно освободить 0,5–1 ГБ на телефоне; это запас, не измеренный
размер готовой установки. На ПК .NET/Android SDK требуют существенно больше места.
