# Архитектура

## Слои

`Mostik.Core` не зависит от Android: направления, политика текста, спецификация пакетов,
проверка ZIP и отбор офлайн-голосов. `Mostik.Android` содержит нативный интерфейс Android
и четыре реальных сервиса. `Mostik.Core.Smoke` — исполняемые узкие проверки без тестового NuGet.

| Файл | Ответственность |
|---|---|
| MainActivity.cs | UI, разрешение микрофона, последовательность операций, lifecycle |
| ModelStore.cs | HTTPS download, размер, SHA-256, staging, установка и наличие моделей |
| VoskNative.cs | Минимальный P/Invoke C API, копирование native JSON в managed string |
| VoskSpeechService.cs | Одна модель в памяти, PCM16 16 kHz mono, промежуточный и итоговый текст |
| OfflineTranslator.cs | Два локальных ML Kit translator; download только в подготовке |
| GoogleTask.cs | Привязка Google Task к TaskCompletionSource, обработка отмены ожидания |
| OfflineSpeechService.cs | Инициализация TTS, локальный Voice, ожидание utterance, stop |

## Последовательность реплики

```text
Ожидание → выбор RU/PL → проверка пакета → загрузка модели в RAM → микрофон
→ Vosk partial/final → закрытие микрофона → [правка текста] → ML Kit Translate
→ показ перевода → локальный TTS → OnDone + акустическая пауза → ожидание
```

Одновременно разрешена одна операция экрана. Второе нажатие активной кнопки во время
записи завершает фразу, другая кнопка заблокирована. Отмена останавливает запись/озвучку.
Нативную модель нельзя освободить, пока не завершилась задача распознавания. OnDestroy
дожидается активной managed-задачи, затем освобождает сервисы. Progress от завершившейся
записи ограждён флагом, чтобы не перезаписать перевод.

Уход приложения с экрана отменяет текущую операцию. Частичная загрузка Vosk удаляется,
последующая попытка начинается с начала. Google Task не предоставляет здесь отмену
уже начатого download: мы отменяем только ожидание и последующие действия. Это описано UI.
После возврата с системных настроек TTS создаётся заново, список голосов обновляется.

## Память и задержка

Vosk-модель одна: переключение языка освобождает предыдущую. Это исходный компромисс
для телефона с неизвестной доступной RAM, не утверждение об оптимальной скорости.
Загрузка модели выполняется вне UI, но её native вызов не умеет прерываться мгновенно.
Следующая операция не должна начинаться до возврата этого вызова. Два ML Kit translator
создаются по требованию и сохраняются; потребление всего процесса ещё не измерено.

Порог завершения речи использует endpoint Vosk, а не самодельный RMS-VAD. RMS только
показывает уровень микрофона. Ограничение записи 30 секунд; без распознанных слов около
10 секунд. Шум может давать ложные слова: это проверяется на Redmi в магазине, не моками.

## Данные и границы

PCM находится только в оперативной памяти. Тексты — в виджетах и полях Activity;
намеренная история не реализована. Настройки чекбоксов в private SharedPreferences.
Vosk-модели — private NoBackupFilesDir/vosk; ML Kit хранит свои модели самостоятельно.
Native build assets не помещаются в Git. В APK должны войти ARM64 .so, models.json,
информация о данных/лицензиях и официальный Google powered-by бейдж.

Структурный `.complete` проверяет установку, а не хэш каждого распакованного файла
при каждом старте. Полная SHA-проверка выполняется перед распаковкой скачанного ZIP.
Внутреннее хранилище не защищает от root/повреждения файловой системы; это не DRM.

## Известные границы первой версии

Нет audio-focus политики для всех OEM/Bluetooth, фоновой службы, импорта пакета с SD,
загрузки Vosk с продолжением, автоматического выбора голосового движка, гарантии
правильного перевода имён/денег/отрицаний и измеренного SLA задержки.
Не обещать отсутствие любой сетевой активности ML Kit при включённой сети: SDK может
посылать технические метрики, хотя тексты обрабатывает на устройстве.
