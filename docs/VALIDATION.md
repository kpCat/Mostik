# Проверки исходной поставки

Дата: 2026-09-08. Версия: 0.1.0.

## Что действительно выполнено

В Linux-среде подготовки выполнена команда:

```text
python scripts/validate_source.py --json <путь отчёта>
```

Exit code: **0**. Результат: **STRUCTURE_PASS_ONLY**, 35 структурных проверок.
Машиночитаемый отчёт: `docs/validation/initial-structure-report.json`.
Разбираются XML и JSON; проверяются относительные ссылки, проекты решения, каталог
моделей, формат хэшей, разрешения, отсутствие вызова download в теле TranslateAsync,
отсутствие ключей/непроверенных бинарников и UTF-8 BOM в PowerShell.

Дополнительно исходники C# пропущены через лексер Pygments: ошибок лексера и несогласованных
пар скобок не найдено. Это **не** C# parser/type checking и **не** компиляция.
Проведён ручной разбор последовательности ASR → Translate → TTS и исправлены поздние
UI callbacks записи/загрузки, очистка прежнего перевода при новой операции и отмена.
Структурные проверки наличия строк не доказывают корректность исполнения этих алгоритмов.

После реальных проверок дополнять этот документ новыми датированными результатами;
не переписывать историю подготовки так, будто исходный архив был проверенным релизом.

## Первая Windows-сборка — 2026-09-08

Исторические статусы исходной поставки выше сохранены. На Visual Studio Enterprise 2026
18.0.11205.157 с .NET SDK 10.0.100 и Android workload 36.1.2 выполнены restore,
Core.Smoke и `SignAndroidPackage`. Core.Smoke: **38 PASS, 0 FAIL**. Исправлены реальные
конфликты C#-типов Android/.NET, актуальные binding-имена AudioRecord и clipboard,
обработка нового TTS error callback и двойное включение собственного `libvosk.so`.

Создан `artifacts/Mostik-0.1.0-debug.apk`, размер 45 437 847 байт, SHA-256:
`7a8f167dbbcb8d27399c78e66dc8c146a8aeeded3afb2eb7e1f6b5d2c9983359`.
`apksigner` подтвердил debug-подпись v2/v3, `zipalign` — корректное выравнивание.
В APK нет повторяющихся ZIP entries; присутствуют только ARM64 `libvosk.so` и
`libtranslate_jni.so`, каталог моделей, privacy/third-party assets и registrar-классы.

ADB 36.0.0 запустился, но разрешённых устройств в списке не было. Поэтому запуск на
Redmi, загрузка runtime-моделей, реальный микрофон Vosk, оба направления ML Kit,
слышимые офлайн-голоса, авиарежим, задержка и память остаются соответственно
**NOT_TESTED/NOT_MEASURED**, а не объявляются PASS.
