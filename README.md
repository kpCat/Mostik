# Мостик — русский ⇄ польский без интернета

**Версия 0.1.0. Дата исходной поставки: 8 сентября 2026.**

**Статус на 8 сентября 2026: Windows-сборка и Core.Smoke выполнены, debug APK создан.**
Исправлены выявленные первой компиляцией C#-привязки .NET for Android. APK проверен
на подпись, выравнивание, ARM64 native-библиотеки и registrar-классы. Подключённого
ADB-устройства не было, поэтому запуск на Redmi, офлайн-разговор, голоса, задержка и
память остаются NOT_TESTED/NOT_MEASURED. Факты и SHA-256 приведены в
`docs/tasks/GOAL-001-FIRST-DEVICE/RESULT.md` и `docs/VALIDATION.md`.

## Что реализовано

Два больших направления: **«Я говорю»** (русский → польский) и **«Собеседник говорит»**
(польский → русский). После нажатия нужно дождаться сообщения «Говорите».
Речь распознаётся локально Vosk, текст переводится локально ML Kit, результат
показывается крупно и передаётся установленному офлайн-голосу Android.
Микрофон закрывается до озвучивания: приложение не должно переводить собственный голос.

Предусмотрены ручная остановка фразы, завершение после паузы, отмена, индикатор микрофона,
показ промежуточного текста, правка/ручной ввод, повтор перевода голосом, переключатель
озвучки и режим проверки распознанного текста перед переводом. Есть экран подготовки,
проверка наличия пакетов и голосов, проба без активной сети и техническая диагностика.

## Технологии

C# / .NET 10 for Android, нативные Android Views, без MAUI и без WebView.
Vosk вызывается через C API из ARM64 `libvosk.so`; JNA и Java-обёртка Vosk не нужны.
Перевод — `Xamarin.Google.MLKit.Translate` версии `117.0.3.8`.
Озвучка — Android TextToSpeech, только голос без признака необходимости сети
и без признака `notInstalled`. Целевой ABI: ARM64; минимальный Android проекта: API 26.
Это заданные требования проекта, а не результат проверки конкретного Redmi.

В исходниках нет подписки, лимита числа реплик, ключей OpenAI или Cloud Translation.
Скачивание моделей и сторонние компоненты требуют соблюдения их условий.
Поставку нельзя описывать как «полностью open-source стек»: ML Kit и системные голоса
имеют собственные лицензии. См. `docs/THIRD_PARTY.md` и `docs/PRIVACY.md`.

## Важные ограничения

- Первый запуск требует сети для пакетов и отдельной установки русской и польской
  офлайн-озвучки. Сам архив НЕ содержит модели, SDK и нативные бинарные зависимости.
- Быстродействие и точность Redmi Note 9 Pro ещё не измерены. В памяти держится одна
  модель речи: это экономит память, но при смене языка добавляет время загрузки.
- Перевод ML Kit между русским и польским использует английский как промежуточный язык.
  Для сложных фраз качество может снижаться. Проверяйте числа, имена и отрицания.
- Нет постоянного фонового прослушивания, одновременной речи двух людей и автоопределения
  языка. При сворачивании/блокировке активная операция отменяется.
- Установленный флаг офлайн-голоса не доказывает, что вы действительно его услышите:
  нужен тест обоих голосов и обоих направлений в авиарежиме с выключенным Wi-Fi.
