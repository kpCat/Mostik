## Неизменяемые ограничения

- Нет платного API, облачного распознавания/перевода и тихого переключения на сеть.
- Не заменять Vosk на SpeechRecognizer с EXTRA_PREFER_OFFLINE: это не равнозначная гарантия.
- Озвучка: не выбирать голос, который требует сеть или имеет notInstalled.
- Микрофон и TTS не работают одновременно. Не освобождать native model до завершения
  recognizer/capture-задачи. Поздние callback не должны менять новое состояние UI.
- Разговоры и PCM не писать в логи/файлы, телеметрию или clipboard автоматически.
- Не сохранять диалоги «для удобства», не добавлять аналитику или рекламу.
- Не ослаблять SHA-256/size/ZIP checks ради успешного скачивания. Расхождение расследовать.
- ML Kit DownloadModelIfNeeded разрешён ТОЛЬКО в явной подготовке пакетов, не при разговоре.
- Отмена ожидания Google Task не означает отмену underlying SDK download. Не обещать обратное.
- Одна модель Vosk в RAM — исходный экономный режим. Изменять после замеров Redmi, не по догадке.
- Не удалять данные/приложение на телефоне для решения конфликта подписей без явного согласия.
- Не ставить побочные SDK, не обновлять все NuGet и не менять архитектуру без необходимости.

## Окружение и Git

Пользователь разрешил подготовить отсутствующие Android-компоненты. Сначала Doctor.
Использовать существующие VS SDK/JDK либо изолированные .tools; не ломать другие проекты.
Лицензии и UAC не обходить. При блокировке описать точное действие, не зацикливаться.
Не выполнять git reset --hard / clean -fd / force-push.
Для GOAL-001 пользователь ЯВНО разрешил и требует Git commit + push в:
`https://github.com/kpCat/Mostik.git`, ветка `master`.
Перед изменениями проверить `git status` и `git remote -v`. Если `origin` отсутствует —
добавить указанный URL. Если `origin` указывает не на `kpCat/Mostik`, не пушить вслепую:
исправить remote на явно заданный пользователем репозиторий и отразить это в RESULT.md.
Удалённый репозиторий сейчас используется как основной репозиторий проекта.
Не выполнять force-push, не переписывать опубликованную историю и не добавлять секреты,
токены, локальные SDK/.tools, модели, APK/артефакты или персональные логи в Git.
После успешного коммита выполнить `git push -u origin master` и проверить, что удалённый
`master` указывает на тот же commit SHA. Если push блокируется авторизацией/политикой,
не обходить защиту и не публиковать credentials — записать точную ошибку в RESULT.md.
После restore сохранить реально созданные packages.lock.json. Не сочинять lockfile вручную.
После проверки оригинального AAR зафиксировать его SHA-256 в data/build-assets.json,
сохранив URL, версию и источник в docs/DEPENDENCY_LOCK.md.

## Проверки, действительно относящиеся к задаче

Core smoke тестирует текст, направления, запрет сетевых голосов и безопасную распаковку.
Android интеграцию подтверждают сборка и реальный запуск, а не мок возврата «готово».
Не создавать сотни формальных тестов вместо сборки. При существенном дефекте добавить
узкую регрессионную проверку там, где её можно честно выполнить.

Результат каждой задачи: краткий RESULT.md с файлами, командами, exit codes,
путём APK, SHA-256, версиями SDK, реально выполненными тестами, NOT_TESTED и известными рисками.
Не публиковать binlog и adb logcat без очистки возможных персональных путей и секретов.
